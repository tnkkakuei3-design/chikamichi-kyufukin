# ちかみち給付金 — 確認用サイト

既存の4問チェックLPを確認するためのGitHub Pages版です。本番ドメインの設定や内容は変更しません。

## 公開設定

- GitHub Pages: `main` ブランチの `/docs`
- ビルド不要のHTML・CSS・JavaScript
- カスタムドメイン（CNAME）は設定しません
- 確認用のため検索エンジン向けに `noindex` を指定しています。アクセス制限ではありません。

## 内容

- `docs/index.html`: LP
- `docs/styles.css`: レスポンシブ表示
- `docs/app.js`: 4問チェック、結果、コピー、FAQ
- `docs/config.js`: 任意のLINE接続設定（現在は未設定）
- `docs/assets/`: 人物画像・広告画像・アイコン

回答はブラウザー内で確認ポイントを整理するためにのみ使い、外部へ送信しません。受給資格や給付額の判定は行いません。
結果の「公式の案内で確認する」は、ハローワークの公式ページへ遷移します。会社サイトへの変更はまだ行っていません。

## 本運用前の確認事項

運営者情報、サービス内容・料金、広告との表現の整合は別途確認が必要です。この公開は審査通過や本運用の準備完了を意味しません。
