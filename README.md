# ちかみち給付金 — GitHub Pages確認版

雇用保険の基本手当について、条件付きの日数・日額・総額をブラウザ内で試算する無料サービスです。診断から結果表示まで無料で、連絡先登録・LINE誘導・有料サービス契約はありません。

## 構成

- `docs/index.html`: LP、条件・計算根拠、手続き、FAQ
- `docs/app.js`: 7項目を基本とする質問、条件による分岐、試算結果・コピー

診断回答はブラウザメモリのみで処理します。外部送信、永続保存、計測タグはありません。問い合わせはメールまたは電話で、診断とは別です。

## 計算と制限

2026年8月1日基準を使用します。

- 厚生労働省: https://www.mhlw.go.jp/content/001726934.pdf
- 給付日数: https://www.hellowork.mhlw.go.jp/insurance/insurance_benefitdays.html
- 受給要件: https://www.hellowork.mhlw.go.jp/insurance/insurance_basicbenefit.html
- 離職理由区分: https://www.hellowork.mhlw.go.jp/insurance/insurance_range.html

回答された区分が正式に認められ、所定給付日数全日分を受け取る場合の試算です。65歳以上、すぐに働けない場合、再就職決定、未確認・矛盾した入力等では総額を断定しません。平均月給だけが未入力の場合は日数のみ表示します。

就職困難者は窓口確認済みの場合のみ該当区分を使います。雇止めの給付日数特例は2027年3月31日までの離職に限定しています。毎年の金額改定、実際の失業認定、就労・再就職による変動、他の給付や延長給付は計算していません。

45〜59歳・就職困難者・加入1年以上・月給52万円・360日という条件では `8,666円 × 360日 = 3,119,760円` です。この例は制度全体の最大額ではありません。同年齢の日額上限9,110円 × 360日は3,279,600円のため、310万円で結果を切り捨てる処理はありません。

## 広告出稿前に残る確認

- 「最大310万円」は、この例だけで制度全体の上限として裏付けられません。広告の対象条件・基準に対応する根拠を別途確定する必要があります。
- 「回答の目安30秒」は、回答項目が分かっている場合の入力目安として表示。代表的な利用者による実測は未実施です。実測前に「検証済み」と扱わないでください。
- 会社名・責任者・住所・電話・メールは既存のサポートページから引き継いでいます。現在の実際の運営主体・連絡先としての確認は別途必要です。
- 3件の公開体験談は第三者の参考情報であり、自社実績・310万円の証拠ではありません。画像の真正性・有料業者利用の有無を独立検証したものではありません。
