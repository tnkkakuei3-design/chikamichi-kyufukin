05 / PRIVACY

プライバシーポリシー

チェックの回答

4問への回答は、ご利用中のブラウザのメモリ内で確認ポイントを表示するためだけに使用します。当サイトからサーバーや第三者に送信せず、Cookie・ローカルストレージ等への永続保存も行いません。再読み込みすると消えます。氏名・電話番号・メールアドレスを入力する必要はありません。

お問い合わせ

メールでお寄せいただく氏名、メールアドレス、内容などは、お問い合わせへの回答・対応に必要な範囲で取り扱います。対応に不要な情報の提供をお願いすることはありません。個人情報は適切に管理し、法令に基づく場合などを除き、本人の同意なく第三者に提供しません。

サイトの配信・外部リンク

配信事業者は、サイト配信や安全管理のためにIPアドレス等のアクセス情報を処理する場合があります。本サイトに広告計測タグやアクセス解析タグは設置していません。外部の公式案内のリンク先では、それぞれのサイトのポリシーが適用されます。

開示・訂正・削除等のご相談

当社が保有するお問い合わせ情報に関するご相談は、cs@yorimichi.oneへご連絡ください。ご本人の確認を行い、法令に従って対応します。ブラウザ内だけで扱うチェック回答は、当社では保有していません。
